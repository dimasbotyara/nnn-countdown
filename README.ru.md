# Обратный отсчёт Недрочабря (NNN Countdown)

**[🇬🇧 English version: README.md](README.md)**

Небольшое шуточное десктоп-приложение на **Python + customtkinter**: показывает
живой обратный отсчёт по локальным системным часам — до начала
(1 ноября, 00:00) или до конца (1 декабря, 00:00) **«Недрочабря»** (No Nut
November). Двуязычный интерфейс (русский/английский), тёмная тема Ayu Mirage,
настройки сохраняются в `config.json` в системной директории пользователя.

## Возможности

- Два режима отсчёта: **до начала** (ближайшее будущее 1 ноября) и
  **до конца** (ближайшее будущее 1 декабря), с автоматическим переходом
  на следующий год.
- Календарный подсчёт месяцев (а не «по 30 дней»).
- Пять всегда видимых карточек: месяцы, дни, часы, минуты, секунды —
  обновляются каждую секунду из `datetime.now()`.
- Статус-строка: локальное время, часовой пояс и индикатор
  «челлендж активен» (1–30 ноября).
- Переключатель языка (EN/RU), режим «поверх всех окон», кнопка
  «Скопировать», горячие клавиши.
- Шуточная кнопка **«Я проиграл 😭»** с постоянным счётчиком проигрышей.
- Устойчивый конфиг: повреждённый файл сбрасывается к безопасным значениям,
  приложение не падает.

## Установка

Нужен Python 3.9+ с **tkinter** (на Debian/Ubuntu:
`sudo apt install python3-tk`; на macOS/Windows он входит в установщик
с python.org).

```bash
python -m pip install -r requirements.txt
```

Зависимости: только `customtkinter` и `Pillow`.

## Запуск

```bash
python main.py
```

## Режимы, языки и настройки

- **Режим** — переключается в верхней панели («До начала» / «До конца»).
  Цель — ближайшее будущее 1 ноября 00:00 или 1 декабря 00:00 по
  **локальному времени**; если цель этого года уже прошла, отсчёт идёт
  к следующему году.
- **Язык** — переключатель EN/RU в панели; весь интерфейс (включая заголовок
  окна, диалоги и формы множественного числа) меняется сразу.
- **Настройки** (Ctrl+,) — переключатель «Поверх всех окон» и точный путь
  к файлу конфигурации.
- **Удалить конфиг** — после подтверждения удаляет `config.json` и сбрасывает
  настройки работающего приложения к значениям по умолчанию, перезапуск не
  нужен. Файл будет создан заново при следующем сохранении (например, при
  выходе сохраняется геометрия окна).
- **Скопировать** (Ctrl+C) — копирует в буфер обмена строку вида
  `3 месяца, 12 дней, 05:04:03 до Недрочабря`.

Горячие клавиши: `Ctrl+Q` — выход, `Ctrl+,` — настройки, `Ctrl+C` —
скопировать, `F1` — «О событии».

## Где лежит config.json

| ОС      | Путь                                                          |
|---------|---------------------------------------------------------------|
| Linux   | `$XDG_CONFIG_HOME/nnn-countdown/config.json` или `~/.config/nnn-countdown/config.json` |
| macOS   | `~/Library/Application Support/nnn-countdown/config.json`     |
| Windows | `%APPDATA%\nnn-countdown\config.json`                         |

Хранятся: `language`, `mode`, `geometry`, `always_on_top`, `losses`.
Путь определяется вручную в `config.py` (без зависимости `platformdirs`).
Если файла нет — он создаётся с настройками по умолчанию; если он повреждён
— показывается понятное предупреждение и используются безопасные значения.

## Как считается время

Всё построено на **локальном системном времени** (`datetime.now()`, наивные
локальные datetime) — без UTC и жёстко зашитого часового пояса, поэтому
переходы на летнее/зимнее время обрабатывает сама ОС.

Остаток считается в два шага (см. `time_logic.py`):

1. Считаем, сколько **полных календарных месяцев** помещается между «сейчас»
   и целью (`add_months` при необходимости зажимает день: 31 января + 1 месяц
   → 28/29 февраля).
2. Остаток — обычный `timedelta`, разложенный на дни, часы, минуты и секунды.

Пример: 20 августа 10:00 → 1 ноября 00:00 = **2 месяца** (до 20 октября
10:00), **11 дней**, **14 часов**.

## Кнопка «Я проиграл 😭»

Чистая шутка, работающая строго по заданию: нажатие открывает модальное окно
с надписью **`анлак 😭😢`** / **`unlucky 😭😢`** (с маленькой буквы, без
точки). Единственная кнопка — «Продолжить» / «Continue» — закрывает всё
приложение. Перед закрытием в конфиге увеличивается счётчик проигрышей
`losses`; он показывается в окне «О событии». Закрытие окна крестиком
равносильно кнопке «Продолжить». Никакой другой логики у кнопки нет.

В окне «О событии» (F1) также есть счётчик проигрышей, ссылка на README и
кнопка **«Закрыть приложение и удалить конфиг»**.

## Принятые решения по неоднозначным местам

- Ровно в **1 ноября 00:00:00** отсчёт «до начала» целится уже на
  *следующий* год (текущее 1 ноября «уже наступило»); то же для 1 декабря.
- При смене языка открытые вторичные окна перерисовываются на месте,
  перезапуск не нужен.
- Цвета для hover/рамок (`#2C3340`, `#3A4150` и т.п.) — производные оттенки
  заданной палитры Ayu, используются только для интерактивных состояний.
- Формат даты зависит от языка интерфейса (`%Y-%m-%d` для EN, `%d.%m.%Y`
  для RU).

## Ограничения

- Иконка окна ставится через `iconphoto`; на некоторых платформах/WM (или
  при отсутствии Pillow) она может просто не отображаться — приложение при
  этом работает.
- Подпись часового пояса — «как получится»: на большинстве Linux-систем
  показывается IANA-имя (например, `Europe/Moscow`), в других случаях —
  аббревиатура вроде `MSK`.
- После «Удалить конфиг» файл может появиться снова при выходе (сохраняется
  геометрия окна). Если нужно удалить навсегда — используйте кнопку в окне
  «О событии».
